## How to Enable GitHub Pages (5 seconds)

### Step 1: Open Repository Settings
1. Go to: **https://github.com/GareBear99/Neolution**
2. Click **Settings** tab (top right, gear icon)

### Step 2: Find Pages Section
1. In left sidebar, scroll down and click **Pages**
2. Look for "GitHub Pages" section

### Step 3: Enable Pages
1. Under "Source", select **Deploy from a branch**
2. Choose branch: **master**
3. Choose folder: **/ (root)**
4. Click **Save**

### Step 4: Done!
GitHub will deploy within 1-2 minutes.
